# Checklist de entrega de logo

## Versiones
- [ ] Principal (color)
- [ ] Monocroma (negro)
- [ ] Monocroma (blanco / negativo)
- [ ] Símbolo / isotipo suelto
- [ ] Variante horizontal y vertical (si aplica)

## Formatos
- [ ] Vectorial editable (SVG y/o AI)
- [ ] PNG con fondo transparente (varias resoluciones)
- [ ] Favicon (16, 32, 180 px)
- [ ] PDF para impresión

## Verificación
- [ ] Legible a tamaño mínimo
- [ ] Funciona sobre fondo claro y oscuro
- [ ] Contraste suficiente (WCAG)
- [ ] Sin similitud problemática con marcas existentes
- [ ] Área de protección definida
- [ ] Colores en HEX / RGB / CMYK (y Pantone si va a imprenta)
