# Rúbrica de evaluación de un logo

MY MULLER somete cada propuesta a estos seis criterios antes de presentarla y comenta cómo se comporta en cada uno. Puntúa 1–5 y explica.

| Criterio | Pregunta clave | 1–5 |
|----------|----------------|-----|
| **Distinción** | ¿Se diferencia de la competencia y de marcas conocidas? | |
| **Memorabilidad** | ¿Es fácil de recordar y de describir con palabras? | |
| **Escalabilidad** | ¿Funciona de favicon (16 px) a valla publicitaria? | |
| **Atemporalidad** | ¿Sobrevivirá a las modas de los próximos 10 años? | |
| **Pertinencia** | ¿Comunica lo correcto para este negocio y público? | |
| **Reproducibilidad** | ¿Funciona en monocromo, bordado, grabado y pantalla? | |

## Cómo se usa

- Si algún criterio queda por debajo de 3, el diseño no se presenta como final: se señala la debilidad y se propone un ajuste.
- La reproducibilidad se comprueba de verdad: versión monocroma, tamaño mínimo, fondo claro y oscuro.
- La distinción incluye una comprobación honesta de similitud con marcas famosas; si se parece demasiado, se advierte (y se recuerda que el registro de marca es responsabilidad del usuario).
